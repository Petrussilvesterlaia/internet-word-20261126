One word for the whole internet: a program that writes that single word
to `/output/entry.txt`. The word is funny, fitting, and surprising — the
internet at its most itself.

## Run it

```sh
python3 main.py
```

It writes the word to `/output/entry.txt` (no trailing newline), then
reads the file back and verifies it byte for byte.
